# Typing Game

O projeto é um jogo de digitação, ele deverá ter 3 níveis, iniciante, amador, expert.

### Iniciante

O nivel iniciante contará com 10 palavras, e um timer de 35 segundos, as palavras devem ser em português, as iniciantes não precisam necessariamente conter muitos acentos, afinal é pra uma pessoa não tao acostumada a mexer em teclados

### Amador

O nivel amador contará com 15 palavras, e um timer de 30 segundos, as palavras devem ser em português, podem ter acentos moderados, nada complexo demais porém uns acentos.

### Expert

O nivel amador contará com 30 palavras, e um timer de 40 segundos, as palavras devem ser em português, podem ter acentos e daquels bem complexos, sem medo, pode ser díficil.

### Projeto

O projeto deve ser feito com tecnologias web, um framework web pra ter uma indexação boa, e bom SEO, visual moderno de jogo, estilo termo e contexto.

Aplique boas práticas de codigo, coisas como, o projeto não deve ter try catch, devermos usar funcoes em arquivos sem necessariamente classes, sem necessariamente ID.

Aplique uma validação de code review a cada etapa concluida, e essa validação deve manter-se alinhada, achou erro -> corrigiu -> rodou novamente, isso ate ficar concluida.

As principais cores do projeto devem ser Modo claro: Azul marinho, e preto, Modo escuro: Azul marinho e branco
